Generated by `compare-sweep.py` from the JSON in `results-v2/`. Each cell is the percentage change
versus `main`; the `main` column is in ops/ms. See README.md for what the variants are and how the
stages were run. The first main-vs-branch pass (older code) is in `results-v1.md`.

of `pressureA` and `pressureB` (`-f 1`). Cold is a single run (`coldA`, `-f 1`). Rows whose code is
identical in every variant (`mmap_T*`, `mmapRandom_T*`, `retrieveNoPrefetch_*`) show the noise
floor; the pressure and cold T08 stored-fields rows are noisy at `-f 1`.
